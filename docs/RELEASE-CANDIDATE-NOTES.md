# Every Morning Fortune 1.0.0 RC1

## 公開候補版の目的

正式公開前に、UI、PWA、データ保存、Studio、iPhone実機動作をまとめて確認する。

## 主な確認対象

- 初回登録体験
- 朝の運勢表示
- 夜の振り返り
- IndexedDB保存
- Studio編集
- Studio品質チェック
- JSON入出力
- PWAインストール
- オフライン起動
- iPhone画面サイズ差

## 正式版へ進む条件

- 致命的なJavaScriptエラーがない
- データ消失がない
- 横スクロールがない
- 小型iPhoneでも主要操作ができる
- PWA起動が安定する
- Studioの主要機能が動作する
